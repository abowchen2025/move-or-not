## 2. 本次 wip commit 的內容（給接手的人）

- **`tools/gen-images.mjs`**：點陣資料 → PNG（自寫編碼器，用 Node 內建 zlib）。og:image 用 Playwright Chromium 排版後截圖。執行方式：在 repo 根目錄 `node tools/gen-images.mjs`（需先在 web/ 安裝套件與 chromium）。
- **`web/src/stage/`**
  - `sprite-sheet.ts`：解析 PixiJS spritesheet JSON。自訂欄位放在 `meta.character`：`scale.mobile`／`scale.desktop`、`tripMs`、`frameMs.move`／`frameMs.idle`。
  - `track.ts`：`computeTrack`，向內取整數像素；主角比文字寬時置中（D-22-j）。`measureText` 以 Range 量測文字。
  - `movement.ts`：float／walk 策略，只負責垂直位移，另提供 CSS 近似值。
  - `character.ts`：`CharacterMotion`，以跑道比例保存位置；減少動態時置中並做透明度呼吸。
  - `background.ts`：數量依面積計算並設上限；D-11 減弱倍率。星星刻意不用白色。
  - `director.ts`：決定完結演出播哪一版。
